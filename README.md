# O dia a dia de um QA: A prática de testes manuais funcionais

Desafio de projeto da [DIO](https://www.dio.me/) — ministrado por **Carolina Santana Louzada**, Analista QA na Venturus.

## 🎯 Objetivo do projeto

Revisar conceitos úteis para testes manuais no mundo ágil, praticando atividades do dia a dia de um QA com foco em **testes manuais funcionais**, dentro de um contexto simulado de loja virtual (**SwagLabs Shopping**), utilizando **Scrum**, **JIRA** e **Confluence**.

- **Execução:** Manual
- **Nível:** Sistema e aceite
- **Tipo:** Funcional caixa-preta

## 🧩 Sobre o projeto SwagLabs Shopping

Projeto fictício de e-commerce utilizado como base para praticar todo o ciclo de atividades de qualidade em um time ágil, cobrindo três funcionalidades principais:

- **US-01** — Login na plataforma
- **US-02** — Adicionar produto ao carrinho de compras
- **US-03** — Pagamento via Pix

## 🛠️ Ferramentas e técnicas utilizadas

- **Gerenciamento de projeto:** JIRA (quadros ágeis, Zephyr Scale para casos de teste)
- **Documentação/colaboração:** Confluence
- **Metodologia:** Scrum
- **Técnicas de teste:** Particionamento de equivalência, análise de valor limite, tabela de decisão, BDD (Given/When/Then)
- **Estrutura de User Story:** Princípios INVEST + critérios de aceite em Gherkin
